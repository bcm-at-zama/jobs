Keyboard shortcuts

On Windows / Linux use Ctrl wherever ⌘ is listed.

⌘ RRefresh — re-fetch every source and reload the board.
⌘ IAI fit scores — rate every visible job with Claude.
⌘ UAI fit scores — rate only the visible jobs that don't have a score yet.
⌘ EEdit the companies you track.
⌘ ZUndo the last reject.
⌘ ,Open this Settings page.
EscFrom Settings: go back to the jobs board.
